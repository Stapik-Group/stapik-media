# Ustawienia i pomoc

**Ustawienia → Ustawienia…** otwiera okno ustawień:

- język interfejsu (polski, angielski lub niemiecki),
- motyw,
- czcionka i jej rozmiar,
- czy program sprawdza dostępność nowej wersji.

Gdy na GitHubie pojawi się nowa wersja, program poinformuje Cię o tym i zaproponuje otwarcie jej strony. Nic nie jest pobierane ani instalowane automatycznie.

**Pomoc → Podgląd dziennika** pokazuje, co program robił, co przydaje się przy zgłaszaniu problemu. **Pomoc → Samouczek** (F1) otwiera tę pomoc.
