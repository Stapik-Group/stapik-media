# Łączenie

Wybierz **Plik → Połącz z chmurą** i wpisz adres serwera oraz klucz API. Przycisk **Sprawdź** testuje połączenie, zanim je potwierdzisz.

Jeśli wpiszesz hasło szyfrowania end-to-end, wpisy są szyfrowane na tym urządzeniu, a serwer przechowuje tylko nieczytelne dane. Na każdym urządzeniu używaj tego samego hasła.

Po połączeniu program synchronizuje się w tle, a jego stan widać na dole okna. **Plik → Synchronizuj** uruchamia synchronizację od razu. Zmiany są wysyłane chwilę po ich wprowadzeniu, a przy zamykaniu program wysyła to, co jeszcze czeka.

Jeśli inne urządzenie zapisało nowszą wersję, zachowana zostaje nowsza, a program informuje, że Twoje ostatnie zmiany zostały zastąpione.

**Plik → Rozłącz z chmurą** usuwa klucz API i ustawienia połączenia z tego urządzenia. Wpisy zostają na urządzeniu i w chmurze.

Gdy klucz API wkrótce wygaśnie, program ostrzeże Cię z wyprzedzeniem.
