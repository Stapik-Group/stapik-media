# Settings and help

**Settings → Settings…** opens the settings window:

- the language of the interface (Polish, English or German),
- the theme,
- the font and its size,
- whether the program checks for a newer version.

When a newer version is published on GitHub, the program tells you and offers to open its page. Nothing is downloaded or installed automatically.

**Help → View log** shows what the program has been doing, which is useful when you report a problem. **Help → Tutorial** (F1) opens this help.
