# Connecting

Choose **File → Connect to cloud** and enter the address of the server and your API key. The **Check** button tests the connection before you confirm.

If you fill in the end-to-end encryption passphrase, your entries are encrypted on this device and the server only stores unreadable data. Use the same passphrase on every device.

After connecting, the program synchronizes in the background and shows its state at the bottom of the window. **File → Sync** starts a synchronization at once. Changes are sent a moment after you make them, and the program sends what is still waiting when you close it.

If another device saved a newer version, the newer one is kept and you are told that your latest changes were replaced.

**File → Disconnect from cloud** removes the API key and the connection settings from this device. Your entries stay on the device and in the cloud.

If your API key is about to expire, the program warns you in time.
