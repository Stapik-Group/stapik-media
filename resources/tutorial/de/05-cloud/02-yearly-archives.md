# Jahresarchive

Im Haupt-Cloud-Dokument wird nur das laufende Jahr gespeichert. Jedes frühere Jahr ist ein eigenes Archiv, das bei Bedarf heruntergeladen wird.

Ein Archiv wird heruntergeladen, wenn Sie sein Jahr im Filter **Jahr** wählen. Versuchen Sie, einen Eintrag zu einem früheren Jahr hinzuzufügen, dessen Archiv in der Cloud liegt, aber noch nicht heruntergeladen wurde, bittet Sie das Programm, dieses Jahr zuerst im Filter zu wählen. So wird nichts im Archiv überschrieben.
