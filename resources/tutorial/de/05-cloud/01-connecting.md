# Verbinden

Wählen Sie **Datei → Mit Cloud verbinden** und geben Sie die Serveradresse und Ihren API-Schlüssel ein. Die Schaltfläche **Prüfen** testet die Verbindung, bevor Sie bestätigen.

Wenn Sie die Passphrase für die Ende-zu-Ende-Verschlüsselung eingeben, werden Ihre Einträge auf diesem Gerät verschlüsselt, und der Server speichert nur unlesbare Daten. Verwenden Sie auf jedem Gerät dieselbe Passphrase.

Nach dem Verbinden synchronisiert das Programm im Hintergrund und zeigt seinen Zustand unten im Fenster an. **Datei → Synchronisieren** startet sofort einen Abgleich. Änderungen werden kurz nach der Eingabe gesendet, und beim Schließen sendet das Programm, was noch wartet.

Hat ein anderes Gerät eine neuere Version gespeichert, bleibt die neuere erhalten, und das Programm teilt mit, dass Ihre letzten Änderungen ersetzt wurden.

**Datei → Von der Cloud trennen** entfernt den API-Schlüssel und die Verbindungseinstellungen von diesem Gerät. Die Einträge bleiben auf dem Gerät und in der Cloud.

Läuft Ihr API-Schlüssel bald ab, warnt Sie das Programm rechtzeitig.
