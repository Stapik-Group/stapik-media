# Einstellungen und Hilfe

**Einstellungen → Einstellungen…** öffnet das Einstellungsfenster:

- die Sprache der Oberfläche (Polnisch, Englisch oder Deutsch),
- das Design,
- die Schrift und ihre Größe,
- ob das Programm nach einer neueren Version sucht.

Wird auf GitHub eine neuere Version veröffentlicht, informiert Sie das Programm und bietet an, ihre Seite zu öffnen. Es wird nichts automatisch heruntergeladen oder installiert.

**Hilfe → Protokoll anzeigen** zeigt, was das Programm getan hat, was bei der Meldung eines Problems nützlich ist. **Hilfe → Anleitung** (F1) öffnet diese Hilfe.
